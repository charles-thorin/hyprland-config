# Power menu icons

All five are in place, in the theme's pale white with the same thin line
(1/48 of the icon size, the thickness of the original reboot icon):
`lock.svg`, `logout.svg`, `suspend.svg`, `reboot.svg`, `shutdown.svg`.

Lock, shutdown (power) and suspend were filled shapes, so they were redrawn as
single lines along the same outlines.

Each icon also has an `@2x` copy at double size, used on scaled screens.
